# Grand Theft Argon

1986 cel-shaded 3D open-world action game built in Three.js with procedural city streaming, exotic sports cars, speedboats, helicopters, interactive mini-games, and a 6-star ACPD pursuit system.
> **Create games in AI Studio:** Try building your own 3D games with Argon at **[ai.studio/build](https://ai.studio/build)**.


![Grand Theft Argon](../docs/screenshots/grand-theft-argon.png)

## What it does
- **Cel-shaded 3D world:** Ink-outlined comic shader pipeline with neon reflections, palm boulevards, marinas, downtown towers, and dynamic day/night weather.
- **Land, sea, and air vehicles:** Drive sports cars and muscle cruisers (`F` / `Enter`), pilot speedboats in the harbor, or fly helicopters and seaplanes from the airport.
- **Interactive systems:** Hotwiring and lockpicking mini-games, tactical rampage challenges, and escalating 6-star ACPD police heat.

## How to run
```bash
python3 -m http.server 8082
```
Then open `http://localhost:8082` in your browser.
